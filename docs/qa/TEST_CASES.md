# Especificación de Casos de Prueba (IEEE 829) — Proyecto Narval

> **Plan de Pruebas Base:** `MVP_IEEE829_Narval.docx` (módulos `M1`–`M7`, prioridades `P1`–`P3`, riesgos `R-01`–`R-08`).
> **Fecha de última verificación ejecutada:** `24/11/2026`.
> **Resumen real verificado:** `86` pruebas automatizadas ejecutadas (`63` Backend + `8` Firmware + `15` Frontend), **`86` aprobadas (`100%`), `0` fallidas**. Las pruebas físicas HIL con hardware real ESP32, migración DDL en PostgreSQL/Supabase y UAT en campo quedan marcadas explícitamente como pendientes de ejecución en laboratorio/entorno integrado.
